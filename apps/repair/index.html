Repair

Step 2 of 2. The viewer's captures contain a target image rendered from a new camera angle — but the 3D splat has holes and artifacts where it had to guess. This app sends the original reference photo and the captured target to a FLUX LoRA model that fills in the blanks, producing a clean repaired.png for each capture. Requires a FAL_KEY and explicit paid confirmation before each run. 

POST /api/repair expects multipart files: reference, target, delta_pose, camera and paid_confirm=true
